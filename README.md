## 🚀 Contributing Guidelines

We love open-source contributions! To add your own animation:

1. **Fork** the repository 🍴
2. Create your feature branch: `git checkout -b feature/AmazingAnimation`
3. Add your project folder containing your code and a `README.md` preview image/GIF.
4. Include your developer name (linked to your GitHub profile) and date at the footer.
5. Commit your changes: `git commit -m 'Add AmazingAnimation'`
6. Push to the branch: `git push origin feature/AmazingAnimation`
7. Open a **Pull Request** 🚀
